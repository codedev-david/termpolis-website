🧠 Mneme · the memory that learns

One memory for all your agents

Every AI session normally starts cold, so you re-explain the project and pay tokens to reload it. Mneme reads your past sessions, keeps what matters, and gives every agent the relevant part when it needs it.

  • Learns from every session. When a Claude or Codex agent finishes a task, the fix, the decision or the gotcha is saved as a lesson the others can use. Gemini is asked to record its own.
  • Gets better with use. Memories that help rank higher, ones that don't fade, and contradictions between agents are flagged.
  • Knows your code. A local code graph lets agents find callers and see what a change would break before they edit.
  • Private by default. Embeddings run on your computer, the store is encrypted with a key in your OS keychain, and you can export it all to a .zip.

⚡ Token Headroom · spend less per task

Get more work out of every session

The biggest cost in a long session isn't your prompts. It's the file reads, command output and screenshots sent back to the model on every turn. Termpolis cuts that on your computer before it leaves.

  • Compression on by default for Claude Code. A local proxy shrinks tool output and pasted images, never your words or the model's replies, and keeps the prompt cache intact.
  • The right model for each message. Turn it on and each message goes to the model and effort it needs, decided on your machine in milliseconds.
  • A fresh session when it pays. When starting over would halve the cost of each turn, the pane offers a Fresh session that carries a handoff note forward.
  • An honest receipt. Savings are shown against compressible text, all input and your whole bill, so a big percentage is never mistaken for a big discount.

🛡 AI Security Center

Safer use of hosted models

Any tool that talks to a hosted model sends your prompt to that provider, and Termpolis can't change that. What it can do is catch secrets where they actually escape and check what you install. Every check runs locally and every log stays on your computer.

  • Commit Shield. A commit or push that carries a key is blocked, not just logged: from the Git panel out of the box, and from any terminal or IDE once you install its git hooks.
  • Secrets never enter the memory. They are scrubbed before anything is embedded or written.
  • Safe Import. Third-party skills, plugins and MCP servers are scanned before they install. A red result can't install.
  • Prompts watched. What you type to an agent is checked against 97 secret rules. A hit is recorded and named so you know what to rotate. It doesn't block the prompt, and we say so.
